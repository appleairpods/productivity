# Jacow

Помодоро-таймер с недельным бюджетом фокуса. Без подписки, без аккаунта — все данные хранятся локально в браузере.

## Что умеет

- **Помодоро-таймер** — работа, короткий и длинный перерыв (25/45/50 мин или свои)
- **Направления** — несколько проектов с недельным лимитом в «блоках» (1 блок = 50 мин фокуса + 10 мин отдыха)
- **Задачи** — список задач по направлениям
- **Лимитер недели** — визуализация потраченных блоков по каждому направлению
- **Журнал** — полная история сессий
- **Музыка** — фоновые звуки (дождь, лес, кафе)
- **Экспорт/импорт** — резервная копия данных в JSON
- **RU/EN** — переключение языка
- **Тёмная/светлая тема**

## Как запустить локально

```bash
cd focus-limit-local
python -m http.server 8080
```

Откройте http://localhost:8080

## Резервное копирование

Настройки → **Экспорт данных** → сохраните JSON-файл.  
Для восстановления: **Импорт данных** → выберите файл.
