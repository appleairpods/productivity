# Focus Limit Local

Локальная версия [Focus Limit](https://focuslimit.io) — помодоро-таймер с недельным бюджетом фокуса. Без подписки, без аккаунта, все данные хранятся у вас на компьютере.

## Что умеет

- **Помодоро-таймер** — работа, короткий и длинный перерыв (25/45/50 мин или свои)
- **Направления** — несколько проектов с недельным лимитом в «блоках» (1 блок = 50 мин фокуса + 10 мин отдыха)
- **Задачи** — список задач по направлениям
- **Лимитер недели** — визуализация потраченных блоков по каждому направлению
- **Журнал** — полная история сессий (в отличие от бесплатной версии оригинала, где хранится только текущая неделя)
- **Музыка** — фоновые звуки (дождь, лес, кафе)
- **Экспорт/импорт** — резервная копия данных в JSON
- **RU/EN** — переключение языка
- **Тёмная/светлая тема**

## Что не включено (было Pro в оригинале)

- Облачная синхронизация между устройствами
- ИИ-ассистент и MCP-коннектор
- Синхронизация с Obsidian

## Как запустить локально

### Вариант 1: Просто открыть файл

1. Откройте `index.html` в браузере (Chrome, Edge, Firefox).
2. Данные сохранятся в IndexedDB этого браузера.

> **Важно:** некоторые браузеры блокируют ES-модули при открытии через `file://`. Если страница не работает — используйте вариант 2.

### Вариант 2: Локальный сервер (рекомендуется)

```bash
cd focus-limit-local
npx serve .
```

Или с Python:

```bash
cd focus-limit-local
python -m http.server 8080
```

Откройте http://localhost:8080

## GitHub Pages — стоит ли?

**Да, если хотите:**
- Открывать приложение с любого устройства по ссылке
- Не думать о локальном сервере
- Иметь резервную копию кода

**Нет, если:**
- Нужна только работа на одном компьютере
- Не хотите публиковать код

### Как залить на GitHub Pages

1. Создайте репозиторий на GitHub (можно отдельный, только для этого приложения).
2. Загрузите папку `focus-limit-local`.
3. В Settings → Pages → Source: `main` branch, folder `/` (root).
4. Приложение будет доступно по адресу `https://ваш-логин.github.io/репозиторий/`.

**Данные всё равно локальные:** даже на GitHub Pages информация хранится в IndexedDB вашего браузера, а не на сервере. На другом устройстве данные не появятся — используйте экспорт/импорт JSON.

## Резервное копирование

Настройки → **Экспорт данных** → сохраните JSON-файл.  
Для восстановления: **Импорт данных** → выберите файл.
